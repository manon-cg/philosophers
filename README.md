42 project to solve the Dining Philosophers Problem and explore multithreading and mutexes in C.<br /><br />
To compile: `make`<br />
To run: `./philo <number_of_philosophers> <time_to_die> <time_to_eat> <time_to_sleep> [OPTIONAL: number_of_times_each_philosopher_must_eat]`<br />
All time values are in milliseconds, and the programme is not designed for more than 200 philosophers.<br />
